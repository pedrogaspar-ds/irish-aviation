Twenty one years of Irish aviation

Irish airports carried a record number of passengers in 2025, more than in any year before the financial crisis and more than in any year before the pandemic. This is the whole series, from 2005 to the latest month published, with the questions I asked of it and the answers the data actually gives.

How this was built

Data

Three CSO PxStat tables, pulled through the public API and stored exactly as received in data/raw/: TAA05 annual passengers by airport, TAM08 monthly passengers, TAA06 passengers, freight and flights by market.

Model

Loaded into SQLite as two dimensions and three fact tables, with foreign keys and check constraints, so a bad direction or flight type cannot enter. Every figure here comes from a query over that database, none is typed by hand.

Reproduce it

  • python src/fetch.py
  • python src/build_db.py
  • python src/build_dashboard.py

Caveats

  • 2026 covers January to June only.
  • Market detail starts in 2020, so no market comparison reaches back to 2019.
  • Passengers per flight divides all passengers by all flight movements, including flights that carried only freight.
  • Country figures exclude flights whose market the CSO does not break out.
